# RideGuard

## Getting Started

After cloning the project, install dependencies with Yarn:

```bash
yarn install
```

Start the Expo development server:

```bash
yarn start
```

Then choose a target from the Expo terminal UI, or run one directly:

```bash
yarn android
yarn ios
yarn web
```

For a clean Expo restart after dependency or native configuration changes:

```bash
yarn expo start --clear
```

Before opening a pull request, run:

```bash
yarn lint
```
